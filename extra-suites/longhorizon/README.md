# Long-horizon suite v1 — LEGACY (retired)

> **LEGACY — do not use for scoring or ranking.** This suite (v1: shared
> ~71K-word ledger, 8 tasks, `lh-bench.py`) scored with substring and
> numeric-set checks, which are **gameable**: an answer that echoes the ledger
> can satisfy substring and number-set predicates without answering the
> question, so v1 scores do not measure long-context ability.
>
> **Superseded by v2r** — `extra-suites/longhorizon-v2/` (`lh-bench-v2r.py`,
> strict deterministic scoring, no partial credit).
>
> The v1 result files (`results_*.json`) are kept for provenance only and are
> excluded from the generated leaderboard. Historical v1 numbers survive only
> in pre-retirement snapshots of `results/_published/LEADERBOARD.md`.
